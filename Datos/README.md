# Datos
Esta carpeta contiene los datos necesarios para el proyecto: la secuencia del gen S y de la proteína Spike del SARS-CoV-2, junto con diferentes variantes de esta en formato FASTA.

Estos datos son comunes sirviendo como base para análisis (comparación de las variantes).

## Contenido
- Secuencia de referencia del gen S (FASTA).
- Secuencia de aminoácidos de la proteína Spike (FASTA).
- Secuencia de aminoácidos de diferentes variantes de la proteína Spike (FASTA).

## Fuente de las secuencias
- Proteína Spike: UniProt (P0DTC2 · SPIKE_SARS2).
- Proteína Spike Variante 1: UniProt (P59594 · SPIKE_SARS).
- Proteína Spike Variante 2: UniProt (Q0Q475 · SPIKE_BC279).
- Proteína Spike Variante 3: UniProt (Q3I5J5 · SPIKE_BCRP3).
