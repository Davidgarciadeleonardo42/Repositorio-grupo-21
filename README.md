# Repositorio de la proteína Spike del Sars-Cov-2
Este repositorio contiene análisis de muestras de la proteína Spike del Sars-Cov-2 y variantes. 
| **Carpeta** | **Contenido** |
|---|---|
| **Datos** | Información recogida de bases de datos para este proyecto |
| **Scripts** | Referencia de código utilizado para los distintos análisis a lo largo del proyecto |
| **Muestra** | Muestras empleadas en los experimentos y análisis realizados sobre las mismas |
